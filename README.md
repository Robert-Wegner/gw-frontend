# Galactic War frontend demo

Standalone local-data frontend demo for the FAF Galactic War concept. It preserves the map, solar-system, lobby, battle, inventory, and shop interactions without requiring a backend, login, websocket, or API server.

## Run locally

```bash
npm install
npm run dev
```

Click a star to open a system, then select planets and try the lobby, battle, inventory, and shop controls. Data is deterministic and resets on refresh.

## Build

```bash
npm run build
npm run preview
```
